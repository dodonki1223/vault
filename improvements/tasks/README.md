# Vault 改善 task

この directory は、vault の改善案を 1 task file ずつ管理する場所。

## 書き方

- 1 file 1 改善テーマにする。
- まだ実装しない案でも、背景、ほしい状態、最初にやること、完了条件を残す。
- 実装済みになったら、task file を削除するか、必要な判断だけ別の README / skill / workflow に移す。
- 個人情報、社内限定 URL、具体的な Project 本体の情報は置かない。

## 標準フォーマット

```markdown
# <改善テーマ>

## 背景

-

## ほしい状態

-

## 最初にやること

-

## 関連

-

## 完了条件

-

## 残課題

-
```
